# fftivc.passive.beastmaster

[FINAL FANTASY TACTICS - The Ivalice Chronicles](https://store.steampowered.com/app/1004640/) mod for [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II).

## Usage

Make sure that you have Reloaded-II and download the latest mod in [Releases](https://github.com/epicbrownie/fftivc.ext.beastmaster/releases) (the .7z file).

Add FFTIVC as a registered game within Reloaded-II.

Drag and drop the .7z file to the left pane of Reloaded-II.
